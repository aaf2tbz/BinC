## Remaining top buckets (triage)

1. **undefined name (40)** — almost all cascades from includes absent in the
   vendored clone (raytracing-fallback headers, generated UE headers). Fixes
   live in the corpus (vendor the missing headers) not the compiler.
2. **array/index typing (19)** — `static const float Arr[N] = {...}` const-array
   globals (D3D12 blurShaders) → Phase 4 (const arrays as module globals).
3. **entry detection (17)** — multi-stage files; the audit takes one
   entry/profile per file. Tool-side heuristic work.
4. **other (55)** — ShaderConductor tessellation HS/DS (profile-correct now —
   hs_5_0/ds_5_0 compile; the library-function files are entry artifacts),
   D3D9-style `.fx` blocks → Phase 5/6.
5. **Interlocked on `RWByteAddressBuffer` (4)** — `.InterlockedAdd` on
   byte-address buffers → Phase 4.
6. **texture element types (2)** — non-float texture elements (uint/int
   textures) → Phase 3.
