# HLSL example gallery

Ported DirectX corpus shaders, each verified against the DXC → SPIR-V →
spirv-cross reference on a real Apple GPU (differential) or rendered against
pinned goldens (D3D9 `.fx`). Status as of v0.2.0.

## Render (VS + PS pairs)

| Example | Source | Status | How to verify |
|---|---|---|---|
| `HelloTriangle-shaders.hlsl` | D3D12HelloWorld | pixel-identical vs reference | `make render-diff` |
| HelloFrameBuffering / HelloBundles shaders | D3D12HelloWorld | pixel-identical vs reference | `make render-diff` |
| `mrt.hlsl` | two render targets (base + key) | pixel-identical vs reference | `make render-diff` |
| `matrix.hlsl` | matrix conventions (row-major `mul`) | pixel-identical vs reference | `make render-diff` |
| goldens: `tools/hlsl-diff/goldens/{basichlsl,normalmap,motionblur}` | D3D9 SDK `.fx` | pinned hand-verified pixels | `make golden-d3d9` |

## Compute (kernels)

| Example | Source | Status | How to verify |
|---|---|---|---|
| `half.hlsl` | fp16 storage semantics | 64/64 words match on GPU | `make diff-suite` |
| `nBodyGravityCS.hlsl` | D3D12nBodyGravity (groupshared, barriers, atomics, inout) | 2048/2048 words match | `make diff-nbody` |
| `intrinsics_{math,bits}.hlsl`, `matrix.hlsl`, `overloads.hlsl` | differential suite | word-identical vs reference | `make diff-suite` |

## Running

```sh
# differential (ours vs DXC reference on GPU)
bash tools/hlsl-diff/diff.sh -E main -T cs_5_0 examples/hlsl/nBodyGravityCS.hlsl

# D3D9 golden render
make -C binc golden-d3d9
```

The full corpus coverage table (every `[numthreads]` shader, intrinsics ×
semantics × resources × result) is regenerated by `make -C binc diff-sweep`
into `build/hlsl-diff/coverage.md`.
